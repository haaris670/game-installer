Cool Horror Game

A terrifying standalone desktop horror experience. Face your fears in full-screen immersion. Built using HTML5 and packaged with Electron.

DOWNLOAD FOR WINDOWS

How to Play:

  1. Click the red download button above to get the game package.
  2. Right-click the downloaded .zip file and select Extract All...
  3. Open the extracted folder, find cool-horror-game.exe, and double-click to launch!
  4. Tip: Press F11 to toggle fullscreen mode, and Escape to close the game instantly.
